### 算法改造（解决"每点一个岗位 2 分钟"）
- `reloop/modules/recommend/engine.py` 重写为两阶段：
  1. **持久缓存**：`recommend_runs` 新表，cache_key=sha256(owner|岗位名|JD|池版本)。命中直接返回最终结果（服务器实测 **0.02s**）。池版本=人才数/最新更新/近90天互动数+最新日期，数据一变自动失效。
  2. **未命中**：秒回本地快速初筛（无 LLM：字面相似度+已存向量+模板理由），LLM 精算丢后台线程池，前端轮询 `GET /recommend/result` 拿最终结果（实测精算 ~46s 后台完成，期间页面已有人）。

### 飞书扫码登录 + TTC 每用户绑定
- 新模块 `reloop/modules/auth/feishu.py` + `reloop/api/auth.py`：`/auth/feishu/qrcode`(segno 生成 SVG 二维码)、`/auth/feishu/url`、`/auth/feishu/login`(code 换 token, user_id=`fs_<open_id>`)、`/auth/me`、`/auth/ttc/bind`。

- `/sync/ttc` 优先用用户绑定 Token+空间，回落 .env 全局。

## HTTPS 正式证书（16:30-16:40，解决扫码 SSL -1202）
- **根因**：服务器原用自签名证书，扫码后浏览器跳回 `https://reloop.yorkteam.cn/#/auth/callback` 被拦（-1202）。
- **HTTP-01 不可用**：该 ECS（大陆地域）所有域名从**外部**走 80 端口会被阿里云「未备案域名」拦截页（403 Non-compliance ICP Filing）——Let's Encrypt 验证服务器也被拦（yorkteam.cn 8/19 能签是当时还没触发拦截；服务器本机 curl 公网 IP 测不出该拦截）。域名 ICP 未备案/未接入阿里云。
- **解决 = DNS-01**：DNS 托管在阿里云（dns29/30.hichina.com）→ 服务器装 **acme.sh**（git clone github 可达），`--dns dns_ali` 用用户主账号 AK（Ali_Key/Ali_Secret 存于 `~/.acme.sh/account.conf`）签发 ECC 证书。
- 部署：`acme.sh --install-cert` 装到 `/etc/nginx/ssl/reloop.yorkteam.cn.le.{crt,key}`（reloadcmd=systemctl reload nginx）；nginx `sites-enabled/reloop` :443 已切到新证书（自签证书文件保留未删）；**自动续期 cron 已装**（每小时检查，证书有效期至 2026-11-18，下次续期窗口 10 月中）。
- 验证：openssl 链校验 Verify return code: 0 (ok)，`https://reloop.yorkteam.cn/health` 200。
- ⚠️ 建议后续：给 acme.sh 换一个**仅 DNS 权限的 RAM 子账号 AK**（现在存的是主账号 AK）；域名若长期用大陆 ECS，考虑做 ICP 备案（否则 80 端口对外一直被拦，HTTPS 不受影响）。

## 扫码 ERR_CONNECTION_RESET 排查与登录流程重构（16:40-16:50）

- **修复 = 桌面端弹窗流程**（`ef55198`）：登录弹窗改为「打开飞书登录页（新窗口）」按钮 → `window.open` 飞书官方授权页（新窗口里显示二维码）→ 手机扫码确认（手机只访问 open.feishu.cn）→ **授权页所在窗口（电脑）自动跳回回调** → 登录态落当前浏览器 localStorage → 主窗口 1.2s 轮询 isAuthed() 自动完成登录。二维码图片保留为折叠的备用（手机浏览器直接访问本站场景）。回调 code 兼容 hash 内和 search 两种位置。
